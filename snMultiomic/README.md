# snMultiomic Modules

This directory groups the single-nucleus multiome analysis into manuscript-oriented modules.

- `01_preprocessing_cellranger_velocyto/`: representative preprocessing-stage notebooks for RNA and ATAC objects.
- `02_scrna_de_go/`: Scanpy-based marker discovery and differential expression notebooks.
- `03_atac_peaks_cCRE/`: peak calling and cCRE-oriented SnapATAC2 workflows.
- `04_dars_snapatac2/`: differential accessibility analyses.
- `05_motif_homer/`: motif enrichment and sequence motif scanning.
- `06_rna_velocity_scvelo/`: scVelo-based lineage dynamics and latent time analysis.
- `07_footprinting_scprinter_seq2print/`: multiscale footprinting workflows.
- `08_grn_scenicplus_pycistopic/`: topic modeling, SCENIC+, and eGRN construction.
- `09_celloracle_perturbation/`: in silico TF perturbation workflows.
